# KWU — 3D Asset Research & Production

Fokus dokumentasi, generator aset, inventaris Apple resmi, manekin, backpack, dan botol stainless.

**Mulai dari** [Status Rilis](00_STATUS_RILIS.md), lalu [Spek Apple](01_Research/SPEK_APPLE_RESMI_2026.md), [Kontrak Customizer](02_Production_Briefs/KONTRAK_CUSTOMIZER_MODEL.md), [QA](04_QA/QA_REPORT_V2.md).

**Definisi kualitas:** prototipe prosedural yang telah diuji struktur file dan flow antarmuka, bukan photogrammetric 1:1. Pastikan riset dan dokumen fisik lengkap sebelum klaim akurasi produksi.

Perintah lokal setelah memasang dependensi: `python tools/make_models_v2.py`, `python tools/render_previews.py`, `tsc -p tsconfig.json`, `python tools/check_site.py`.
